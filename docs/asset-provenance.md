# Asset provenance

## Bundled images

`assets/covers/weekly-tech-briefing/*.png` are original geometric images produced by `scripts/generate_demo_assets.py`.

- Creator: project generator script.
- Inputs: numeric colour and geometry constants only.
- Fonts: none.
- Logos: none.
- Photographs or stock assets: none.
- Licence: Apache-2.0 with the repository.

Regenerate them with:

```bash
python scripts/generate_demo_assets.py
```

## Demo screenshot

`docs/images/synthetic-demo.png` is a screenshot of HTML generated from the fictional records under `examples/synthetic/`. It contains no real account data or third-party article text and is licensed with the repository.

## Contributor rule

Every future image, font, video, example dataset or copied code fragment must include its source, author, licence, modification status and redistribution rationale. A URL alone is not proof of redistribution rights.

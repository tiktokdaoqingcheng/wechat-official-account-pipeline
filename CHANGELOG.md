## [0.1.0] - Release candidate

### Added

- Two-article topic-to-publish pipeline with reserve-item replenishment.
- Deterministic content review, optional model roles and bounded recovery.
- Dry-run, draft-only, manual-confirmation and guarded auto-publish modes.
- Frozen manifests, run leases, publish intents, locks, watchdogs and incident replay.
- Offline synthetic demonstration, original deterministic covers and bilingual documentation.
- Public-tree safety scan, lint, tests and GitHub Actions CI.

### Security

- External providers and WeChat writes are disabled by default.
- Credentials, production metadata, real article corpora and private deployment history are excluded from the clean public candidate.
